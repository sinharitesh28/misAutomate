2. Workflow Architecture Overview

1Phase 1: Prepare Excel Plan (--prepare)

  • Logs into MIS via Gmail OTP.
  • Scrapes all mentees across pages and fetches each student's live Attendance % & Gender.
  • Inspects live V2 form questions and generates mentoring_plan.xlsx with Excel dropdown lists and locked @ text date formats.
  • Sets optional/new mandatory fields (such as specialRemarksForHOD, specialRemarksForMentor, otherRemarks) to NA by default.

2Phase 2: Submit & Download (--submit)

  • Reads reviewed rows from mentoring_plan.xlsx.
  • Selects any pending scheduled meeting automatically if present on the portal.
  • Fills Tab 1 (Meeting Details) → clicks Save & Next Step → verifies server response.
  • Fills Tab 2 (Questions Details) → clicks Save → downloads the PDF report in UPPERCASE to downloads/ and marks SUBMITTED_AND_DOWNLOADED in Excel.

3. Pre-Run Configuration (mentoring.json)

Before starting a new mentoring cycle, update mentoring.json with your session date and default remarks:

{
  "startDate": "07-10-2026 09:00 AM",
  "nextMentoringDays": 71,
  "intervalMinutes": 10,
  "attendanceStatus": "Present",
  "parentPresent": false,
  "questionGroup": "Group-1 - PIP",
  "agenda": "Academic Development and Future Readiness",
  "issuesDiscussed": "Balancing coursework with skill development and career exploration.",
  "studentsOpinion": "Found the session helpful and clarifying.",
  "mentorsOpinion": "Student demonstrates good potential and would benefit from structured planning.",
  "suggestions": "Set weekly study goals, seek regular feedback, and explore internships or skill-building workshops.",
  "specialRemarksForHOD": "NA",
  "specialRemarksForMentor": "NA",
  "otherRemarks": "NA"
}
Important Date Rule: nextMentoringDate is automatically calculated as a future date (max(dateOfMentoring, today) + nextMentoringDays) so the MIS portal never rejects it for being in the past. Always keep the DD-MM-YYYY HH:MM AM/PM format if editing dates in Excel.

Command Purpose

5. Execution Commands — Option B: Via Jupyter Notebook

Because Jupyter Notebook on Windows runs inside an interactive event loop, execute main.py via subprocess.Popen in separate cells so live logs stream cleanly without event-loop conflicts.

Jupyter Cell 1: Run Phase 1 (--prepare) & Preview Generated Excel

import os
import subprocess
import sys
from pathlib import Path
import openpyxl

workdir = Path(r"C:\Users\ritya\OneDrive\Desktop\AY26-27\misAutomate\misAutomate_python")
os.chdir(workdir)

env = os.environ.copy()
env["PYTHONIOENCODING"] = "utf-8"

process = subprocess.Popen(
    [sys.executable, "-u", "main.py", "mentoring", "--prepare"],
    cwd=str(workdir),
    env=env,
    stdout=subprocess.PIPE,
    stderr=subprocess.STDOUT,
    text=True,
    encoding="utf-8",
    errors="replace",
)

for line in process.stdout:
    print(line, end="", flush=True)

rc = process.wait()
print(f"\nPhase 1 exited with return code: {rc}")

wb = openpyxl.load_workbook(workdir / "mentoring_plan.xlsx")
ws = wb["Mentoring_Plan"]
headers = [c.value for c in ws[1]]
cols = ["enrollmentNo", "studentName", "attendance", "dateOfMentoring", "nextMentoringDate", "agenda"]
idxs = [headers.index(c) for c in cols if c in headers]
for r in ws.iter_rows(min_row=2, max_row=6, values_only=True):
    print({headers[i]: r[i] for i in idxs})
Pause Between Cells: Open mentoring_plan.xlsx, review or modify any answers, save & close the Excel file, and then run Cell 2 below.

6. Troubleshooting Quick Reference

Symptom Cause & Resolution
PermissionError when running --prepare or --submit mentoring_plan.xlsx is still open in Excel/Calc (look for .~lock.mentoring_plan.xlsx#). Close the spreadsheet window and re-run.
"You have already done mentoring meeting 10 minutes before/after" A mentoring session already exists within ±10 minutes of dateOfMentoring for that student. Adjust dateOfMentoring in Excel and re-run --submit.
"Next Mentoring meeting date must be set to a future date" nextMentoringDate must be strictly later than the current date/time. Ensure it is in DD-MM-YYYY HH:MM AM/PM format and in the future.
Resume an interrupted --submit run Rows already completed are marked SUBMITTED_AND_DOWNLOADED in the status column of mentoring_plan.xlsx and will be skipped automatically on re-run.
